# M08 — Edição, adiamento e cancelamento de lembretes

Entrega local separada do pacote publicado v0.2.0. Branch feat/m08-reminders, esquema 4, dados de teste fictícios.

## Entrega

- Editar descrição e data, com validação de horário futuro.
- Adiar para horário posterior ao anterior, preservando a descrição.
- Cancelar após confirmação. Cancelamento é lógico: sai das pendências e dos avisos, preservando linha e identidade para comprovantes/backups.
- Recusar alterações sobre revisão antiga e sobre lembretes já concluídos/cancelados.
- Reiniciar o estado de aviso ao editar/adiar, permitindo novo alerta na data atualizada.
- Manter os controles e a lista visíveis no tamanho mínimo de janela.

## Evidências

**69 testes locais aprovados**, sem ignorados, em 13/11/2026. A suíte inclui persistência do cancelamento após backup/reabertura, ausência de alertas para cancelados, reaviso após alteração, conflito de revisão, data inválida mantendo o editor e dado original, migração v3→v4 com campos preservados e rollback de falha provocada. Os testes existentes do agente e de migrações antigas continuam aprovados.

A interface real foi aberta com `python -m scripts.demo_workspace --reminder-demo`, banco em memória e lembrete fictício para 14/11/2026 às 10h. Lista e controles Concluir/Editar/Adiar/Cancelar foram conferidos visualmente. Edição/adiamento, confirmações e dados resultantes são exercitados nos testes Tkinter; não se afirma teste de uso diário em equipamento adicional.

## Limites e retorno

Permanece a operação com aplicativo aberto e computador acordado, sem serviço em segundo plano, recorrência ou notificação nativa. Não há reativação de cancelados pela interface. Cancelamentos não removem cópias anteriores. Ferramentas de chat para essas alterações continuam futuras; o M08 usa os botões.

O pacote v0.2.0 continua com esquema 3 e não inclui M08. Para avaliar M08, use esta branch ou o checkout local. Abrir um banco v3 cria backup antes de migrar para v4. O programa v0.2.0 recusa um banco v4; para voltar, preserve os dados atuais e use a cópia compatível anterior. O ensaio desta entrega não abriu o banco pessoal.
