Prévia para Windows 10/11 x64, com Python/Tcl-Tk incluídos.

Baixe o ZIP KiKi-0.2.0-windows-x64.zip, extraia tudo e abra KiKi/KiKi.exe. Não precisa instalar Python ou Git. A pasta _internal precisa acompanhar o executável. SHA-256 disponível em SHA256SUMS.txt.

Inclui os commits de interface, integração local com Ollama, memória com edição e migrações, fontes de contexto, recuperação de backup e pedidos explícitos confirmados. Cada entrega permanece como commit individual no histórico, integrada pelo PR #2.

Memória, lembretes, backup e pedidos confirmados funcionam sem Ollama. Respostas de IA exigem Ollama e qwen3:1.7b instalados separadamente em cada computador. Não são distribuídos dados pessoais, preferências desta máquina, modelos ou bancos. Os dados da conta Windows ficam em %LOCALAPPDATA%\KiKi.

Limites: versão de avaliação, sem assinatura digital própria. Lembretes exigem a KiKi aberta e computador acordado. Sem sincronização entre computadores. A gramática de pedidos é limitada; respostas/citações do modelo podem errar. Teste com a rede desligada e aceite durante uso diário seguem pendentes.

O pipeline testa o código em Windows/Linux e Python 3.11–3.13 e executa uma verificação da interface/persistência no EXE com dados fictícios. Isso não equivale a validação em todos os computadores ou configurações de Windows.

Instruções completas no LEIA-ME.txt do ZIP e em docs/USO-WINDOWS.md no repositório.
